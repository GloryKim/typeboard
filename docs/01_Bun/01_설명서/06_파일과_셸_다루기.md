# 6. 파일과 셸 다루기

## 파일 쓰기: Bun.write

```ts
await Bun.write("memo.txt", "첫 번째 메모\n");
```

- 파일이 없으면 만들고, 있으면 **덮어씁니다.** 들어갈 폴더가 없으면 폴더도 만들어 줍니다(`Bun.write("a/b/memo.txt", ...)`).
- 돌려주는 값은 쓴 **바이트 수**입니다.
- `await`는 "작업이 끝날 때까지 기다린다"는 뜻입니다. Bun의 `.ts` 파일에서는 함수 밖(파일 맨 바깥)에서도 바로 쓸 수 있습니다.

### 덮어쓰지 않고 뒤에 이어 쓰기

`Bun.write`에는 이어 쓰기 기능이 없습니다. 로그처럼 뒤에 계속 붙일 때는 Node.js의 `appendFile`을 씁니다.

```ts
import { appendFile } from "node:fs/promises";

await Bun.write("log.txt", "첫 줄\n");
await appendFile("log.txt", "둘째 줄\n");
console.log(await Bun.file("log.txt").text());
```

```text
첫 줄
둘째 줄
```

## 파일 읽기: Bun.file

`Bun.file()`은 파일을 가리키는 객체를 만듭니다. 내용은 필요한 방식으로 꺼냅니다.

```ts
const memo = Bun.file("memo.txt");

console.log(await memo.exists(), memo.size, "bytes"); // 파일이 있는지, 크기
console.log(await memo.text());                       // 문자열로 읽기
```

```text
true 18 bytes
첫 번째 메모
```

> 파일은 보통 UTF-8 방식으로 저장되는데, UTF-8에서 한글은 한 글자가 3바이트입니다. 그래서 글자 수와 바이트 수가 다릅니다.

| 메서드 | 결과 |
|---|---|
| `await file.text()` | 문자열 |
| `await file.json()` | JSON을 해석한 객체 |
| `await file.bytes()` | 바이트 배열(`Uint8Array`). 이미지 같은 이진 파일용 |
| `await file.exists()` | 파일이 있으면 `true` |
| `await file.delete()` | 파일 삭제 |
| `file.size` | 크기(바이트). 파일이 없으면 `0` |
| `file.type` | 파일 종류. 예: `text/plain;charset=utf-8` |

알아 둘 점:

- **`Bun.file()`만으로는 파일을 읽지 않습니다.** 파일을 가리키기만 하고, `.text()` 같은 메서드를 부를 때 실제로 읽습니다. 그래서 없는 파일로 `Bun.file()`을 만들어도 오류가 나지 않습니다.
- **없는 파일을 읽으면 오류가 납니다.** `.text()`가 `ENOENT`(파일 없음) 오류를 던집니다. 먼저 `exists()`로 확인하거나 `try/catch`로 감싸세요.

```ts
try {
  await Bun.file("없는파일.txt").text();
} catch (err) {
  console.log("오류:", (err as NodeJS.ErrnoException).code);
}
```

```text
오류: ENOENT
```

- **파일 복사:** `await Bun.write("copy.txt", Bun.file("original.txt"))`처럼 `Bun.file`을 그대로 넘기면 복사됩니다.
- **경로 기준:** `"memo.txt"`처럼 쓰면 **명령을 실행한 폴더**를 기준으로 찾습니다. 코드 파일 옆의 파일을 찾으려면 `` `${import.meta.dir}/memo.txt` ``를 씁니다([4장](./04_%EC%BD%94%EB%93%9C_%EC%8B%A4%ED%96%89%EA%B3%BC_%EC%9E%90%EB%8F%99_%EC%9E%AC%EC%8B%A4%ED%96%89.md#%EC%A7%80%EA%B8%88-%EC%8B%A4%ED%96%89-%EC%A4%91%EC%9D%B8-%ED%8C%8C%EC%9D%BC-%EC%A0%95%EB%B3%B4-importmeta)).

## JSON 파일 저장과 읽기

```ts
await Bun.write("user.json", JSON.stringify({ name: "철수", age: 20 }));

const user = await Bun.file("user.json").json();
console.log(user.name, user.age);
```

```text
철수 20
```

## 폴더와 경로 다루기

`Bun.file`과 `Bun.write`는 파일 하나를 다룹니다. 폴더를 만들거나 목록을 보거나 지울 때는 Node.js 모듈(`node:fs/promises`, `node:path`)을 씁니다.

`dir.ts`:

```ts
import { mkdir, readdir, rm, stat } from "node:fs/promises";
import { basename, extname, join } from "node:path";

await mkdir(join("data", "2026", "10"), { recursive: true }); // 폴더 만들기 (중간 폴더까지)
await Bun.write(join("data", "a.txt"), "A");
await Bun.write(join("data", "b.json"), "{}");

console.log(await readdir("data"));                      // 바로 아래 목록
console.log(await readdir("data", { recursive: true })); // 하위 폴더까지 전부

const info = await stat(join("data", "a.txt"));
console.log(info.isFile(), info.isDirectory(), info.size);

const p = join("data", "2026", "report.final.txt");
console.log(p, basename(p), extname(p));

await rm("data", { recursive: true, force: true });       // 폴더째 삭제
console.log(await Bun.file("data/a.txt").exists());
```

```text
[ "2026", "a.txt", "b.json" ]
[ "2026", "a.txt", "b.json", "2026/10" ]
true false 1
data/2026/report.final.txt report.final.txt .txt
false
```

| 함수 | 하는 일 |
|---|---|
| `mkdir(경로, { recursive: true })` | 폴더 만들기. `recursive`가 있으면 중간 폴더도 만들고, 이미 있어도 오류가 나지 않음 |
| `readdir(경로)` | 폴더 안의 이름 목록 (순서는 보장되지 않음) |
| `stat(경로)` | 파일인지 폴더인지, 크기, 수정 시간 등 |
| `rm(경로, { recursive: true, force: true })` | 폴더와 안의 내용을 모두 삭제. **되돌릴 수 없으니** 경로를 꼭 확인 |
| `join("a", "b.txt")` | 경로 이어 붙이기. 운영체제에 맞는 구분자(`/` 또는 `\`)를 써 줌 |
| `basename(경로)` / `extname(경로)` | 파일 이름 / 확장자 |

- 경로를 `"data/" + name`처럼 문자열로 붙이기보다 `join`을 쓰면 `/`가 빠지거나 두 번 들어가는 실수를 막고, Windows에서도 동작합니다.
- `*.md`처럼 **패턴으로** 파일을 찾을 때는 Bun의 `Bun.Glob`이 편합니다([12장 예제 5](./12_%EC%98%88%EC%A0%9C_%EC%8A%A4%ED%81%AC%EB%A6%BD%ED%8A%B8%EC%99%80_%ED%8C%8C%EC%9D%BC.md#%EC%98%88%EC%A0%9C-5-%ED%8C%A8%ED%84%B4%EC%9C%BC%EB%A1%9C-%ED%8C%8C%EC%9D%BC-%EC%B0%BE%EA%B8%B0-bunglob)).

## Node.js 방식도 그대로 됩니다

이미 알고 있는 Node.js 코드를 그대로 써도 됩니다.

```ts
import { readFile, writeFile } from "node:fs/promises";

await writeFile("hello.txt", "안녕");
console.log(await readFile("hello.txt", "utf8"));
```

## 셸 명령 실행: Bun Shell

터미널 명령을 코드에서 실행할 때는 `$`를 씁니다.

```ts
import { $ } from "bun";

const files = await $`ls *.ts`.text();
console.log(files);
```

```text
env.ts
files.ts
index.ts
...
```

- `` $`명령` ``은 명령을 실행하고 결과를 터미널에 보여 줍니다.
- 뒤에 `.text()`를 붙이면 결과를 화면에 보여 주지 않고 문자열로 돌려줍니다.
- 변수를 넣을 때는 `` $`ls ${folder}` ``처럼 씁니다. Bun이 공백과 특수문자를 안전하게 처리해 줍니다. 그래서 사용자가 입력한 값을 넣어도 `; rm -rf /` 같은 다른 명령으로 바뀌지 않습니다.
- **명령이 실패하면(종료 코드가 0이 아니면) 오류를 던집니다.** 실패해도 계속 진행하려면 `.nothrow()`를 붙이고 `exitCode`를 확인합니다([12장 예제 6](./12_%EC%98%88%EC%A0%9C_%EC%8A%A4%ED%81%AC%EB%A6%BD%ED%8A%B8%EC%99%80_%ED%8C%8C%EC%9D%BC.md#예제-6-bun-shell-더-써-보기)).

### 어느 운영체제에서나 되나요?

`ls`, `cd`, `rm`, `mkdir`, `echo`, `cat`, `pwd`, `mv`, `touch`, `which` 같은 자주 쓰는 명령은 **Bun이 직접 구현해 두어서** macOS, Linux, Windows에서 똑같이 동작합니다. 파이프(`|`), 리디렉션(`>`), `&&`도 Bun이 처리합니다.

그 밖의 명령(`git`, `sort`, `grep` 등)은 컴퓨터에 설치된 프로그램을 실행하므로, 그 프로그램이 없는 운영체제에서는 동작하지 않습니다.
