# 2. 설치와 업그레이드

## 설치하기

운영체제에 맞는 방법 하나를 고르세요.

### macOS · Linux (권장)

```bash
curl -fsSL https://bun.com/install | bash
```

설치가 끝나면 터미널을 **새로 열거나**, 안내에 나온 대로 설정 파일을 다시 읽어 주세요.

```bash
source ~/.zshrc   # zsh를 쓰는 경우 (macOS 기본)
```

Bun은 `~/.bun/bin/bun`에 설치되고, 설치 스크립트가 이 경로를 `PATH`에 추가합니다.

### 이 설명서와 같은 1.4.3 버전으로 설치하기

특정 버전을 설치하려면 버전 이름을 붙입니다.

```bash
curl -fsSL https://bun.com/install | bash -s "bun-v1.4.3"
```

### Homebrew (macOS)

```bash
brew install oven-sh/bun/bun
```

### npm (이미 Node.js가 있는 경우)

```bash
npm install -g bun
```

### Windows (PowerShell)

```powershell
powershell -c "irm bun.com/install.ps1 | iex"
```

## 설치 확인

```bash
bun --version
```

출력 예시:

```text
1.4.3
```

빌드 번호까지 보려면 `--revision`을 씁니다.

```bash
bun --revision
```

```text
1.4.3+c6da4a4d3
```

## 업그레이드

이미 설치된 Bun을 최신 안정 버전으로 올립니다.

```bash
bun upgrade
```

| 명령 | 설명 |
|---|---|
| `bun upgrade` | 최신 **안정(stable)** 버전으로 업그레이드 |
| `bun upgrade --canary` | 아직 정식 출시되지 않은 **미리보기(canary)** 버전으로 업그레이드. Bun 개발 저장소에 변경이 들어갈 때마다 새로 만들어지는 버전이라 불안정할 수 있습니다. 연습용으로만 쓰세요. |
| `bun upgrade --stable` | canary를 쓰다가 다시 최신 안정 버전으로 돌아오기 |

> 버전을 정확히 1.4.3으로 맞추고 싶다면 `bun upgrade` 대신 위의 "1.4.3 버전으로 설치하기" 명령을 쓰세요. `bun upgrade`는 항상 최신 버전을 설치합니다.
>
> Homebrew나 npm으로 설치했다면 `bun upgrade` 대신 그 도구로 업그레이드하세요(`brew upgrade bun`, `npm install -g bun@latest`). 설치한 방법과 업그레이드 방법을 맞춰야 버전이 꼬이지 않습니다.

## 버전 번호 읽는 법

`1.4.3`은 `주.부.수`(major.minor.patch) 순서입니다.

| 자리 | 바뀌는 경우 | 예 |
|---|---|---|
| 주(major) | 기존 코드가 안 돌아갈 수 있는 큰 변경 | `1.x.x` → `2.0.0` |
| 부(minor) | 새 기능 추가 | `1.3.x` → `1.4.0` |
| 수(patch) | 버그 수정, 작은 기능 | `1.4.2` → `1.4.3` |

npm 패키지 버전도 같은 규칙을 씁니다([5장](./05_%ED%8C%A8%ED%82%A4%EC%A7%80_%EA%B4%80%EB%A6%AC.md#버전-범위-읽는-법)).

## 도움말 보는 법

명령이 기억나지 않을 때는 도움말을 보세요.

```bash
bun --help          # 전체 명령 목록
bun add --help      # 특정 명령의 옵션
```

## 삭제하기

설치 스크립트로 설치했다면 `~/.bun` 폴더를 지우고, 셸 설정 파일(`~/.zshrc` 등)에서 설치 스크립트가 추가한 `BUN_INSTALL`, `PATH` 줄을 지웁니다.

```bash
rm -rf ~/.bun
```

Homebrew로 설치했다면 `brew uninstall bun`, npm으로 설치했다면 `npm uninstall -g bun`을 씁니다.

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `command not found: bun` | 터미널을 새로 열거나 `source ~/.zshrc`를 실행하세요. 그래도 안 되면 `~/.bun/bin`이 `PATH`에 있는지 확인하세요. |
| 버전이 예상과 다름 | `which bun`으로 어떤 경로의 Bun이 실행되는지 확인하세요. Homebrew와 설치 스크립트로 두 번 설치하면 두 개가 생길 수 있습니다. |
