# 1. Bun 소개

## Bun이란?

**Bun**(번)은 JavaScript와 TypeScript를 실행하는 프로그램(런타임)입니다. Node.js와 같은 역할을 하지만, 개발에 필요한 도구를 한 프로그램에 모두 담고 있다는 점이 다릅니다.

| 역할 | Bun 명령 | Node.js 생태계에서 비슷한 도구 |
|---|---|---|
| 코드 실행 | `bun run index.ts` | `node`, `ts-node`, `tsx` |
| 패키지 설치 | `bun install`, `bun add` | `npm`, `yarn`, `pnpm` |
| 패키지 바로 실행 | `bunx` (`bun x`) | `npx` |
| 테스트 | `bun test` | Jest, Vitest |
| 번들링(빌드) | `bun build` | esbuild, webpack |
| 타입 검사 | `bun check` (1.4.3 신규) | `tsc --noEmit` |

즉 Bun 하나만 설치하면 **실행 → 패키지 관리 → 테스트 → 빌드**까지 할 수 있습니다.

## 왜 Bun을 쓰나요?

- **TypeScript를 바로 실행합니다.** `.ts` 파일을 따로 변환(컴파일)하지 않고 `bun index.ts`로 실행합니다.
- **빠릅니다.** 프로그램 시작과 패키지 설치가 빠릅니다.
- **설정이 적습니다.** `.env` 파일 읽기, JSX, ES 모듈 같은 기능이 기본으로 켜져 있습니다.
- **Node.js와 호환됩니다.** `node:fs`, `node:path` 같은 Node.js 모듈과 npm 패키지 대부분을 그대로 쓸 수 있습니다.

## 런타임이 뭔가요?

JavaScript는 원래 브라우저 안에서만 돌던 언어입니다. **런타임**은 브라우저 밖(내 컴퓨터, 서버)에서 JavaScript를 실행해 주는 프로그램입니다. 런타임은 코드를 실행하는 **엔진**에 파일 읽기, 네트워크, 프로세스 실행 같은 기능을 더한 것입니다.

| 런타임 | 엔진 |
|---|---|
| Node.js, Deno | V8 (Chrome과 같은 엔진) |
| Bun | JavaScriptCore (Safari와 같은 엔진) |

엔진이 달라도 JavaScript 문법은 같습니다. 그래서 Node.js용으로 쓴 코드 대부분이 Bun에서도 그대로 돌아갑니다.

## Bun 전용 기능과 표준 기능

설명서에는 두 종류의 기능이 섞여 나옵니다. 구분해 두면 다른 런타임으로 옮길 때 헷갈리지 않습니다.

| 종류 | 예 | 다른 곳에서도 되나요? |
|---|---|---|
| 웹 표준 | `fetch`, `Response`, `Request`, `URL`, `WebSocket`, `crypto.randomUUID()` | 브라우저, Node.js, Deno에서도 됩니다 |
| Node.js 모듈 | `node:fs`, `node:path`, `process.env` | Node.js와 Bun에서 됩니다 |
| Bun 전용 | `Bun.serve`, `Bun.file`, `Bun.write`, `` $`명령` ``, `bun:sqlite`, `bun:test` | **Bun에서만** 됩니다 |

## 이 설명서에 대해

- **대상:** JavaScript를 조금 써 봤고 Bun은 처음인 분
- **기준 버전:** Bun **1.4.3** (`1.4.3+c6da4a4d3`)
- **확인 환경:** macOS (Apple Silicon), Bun 1.4.3. 모든 장의 명령과 예제를 직접 실행해 나온 결과를 그대로 실었습니다.
- **표기:** 코드 상자는 세 종류입니다.
  - 터미널 명령(`bash`): 터미널에 그대로 입력합니다. 앞에 `$`를 붙이지 않았습니다.
  - 코드(`ts`, `json` 등): 파일에 적는 내용입니다. 상자 위에 파일 이름을 적어 두었습니다.
  - 출력(`text`): 명령을 실행했을 때 화면에 나오는 결과입니다. 버전, 시간, 경로는 컴퓨터마다 다를 수 있습니다.
