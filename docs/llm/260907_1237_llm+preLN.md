# 최신 LLM이 Pre-LN을 쓰는 이유

출처 : [https://www.youtube.com/watch?v=hb_b6tIQgDI](https://www.youtube.com/watch?v=hb_b6tIQgDI)

## 요약

Vaswani et al. (2017)의 원본 Transformer는 **Post-LN**(residual 합 뒤에 LayerNorm)을 썼다. Gemma, Llama, Qwen, DeepSeek, Kimi 계열 등 최근 open-weight LLM과 Diffusion Transformer 계열은 대부분 **Pre-LN**(서브레이어 입력 앞에 정규화)으로 바뀌었다. 정규화 종류도 LayerNorm 대신 **RMSNorm**을 쓰는 경우가 많다.

이 핵심은 표현력이 아니라 **학습 안정성**이다. Xiong et al. (2020)은 초기화 시점에서 Post-LN의 출력 근처 gradient 기댓값이 깊이 L과 무관하게 크게 남고, Pre-LN에서는 LayerNorm Jacobian이 입력 노름(대략 \propto \sqrt{L})으로 스케일을 눌러 **업데이트 크기가 깊이 방향으로 더 고르게** 유지된다고 보였다. 그 결과 Post-LN은 warm-up 없이 큰 learning rate를 쓰기 어렵고, Pre-LN은 warm-up을 줄이거나 제거할 수 있으며 깊은 스택에서도 발산 위험이 작다.

---



## 1. 배경: 원본 Transformer vs 최신 디코더


| 항목      | 원본 Transformer (2017) | 최근 LLM 디코더           |
| ------- | --------------------- | -------------------- |
| Norm 위치 | Post-LN               | Pre-LN               |
| Norm 종류 | LayerNorm             | 대개 RMSNorm           |
| 깊이      | 수~수십 층                | 수십~백수십 층             |
| 학습 관례   | LR warm-up가 사실상 필수    | Pre-LN + 스케줄로 안정성 확보 |


블록 한 층의 차이를 기호로 쓰면 다음과 같다. F는 Attention 또는 FFN이다.

**Post-LN**


x_{\ell+1} = \mathrm{LN}\bigl(x_{\ell} + F(x_{\ell})\bigr)


**Pre-LN**


x_{\ell+1} = x_{\ell} + F\bigl(\mathrm{LN}(x_{\ell})\bigr)


Pre-LN 스택의 맨 끝에는 보통 **최종 LayerNorm/RMSNorm**이 한 번 더 붙는다(예측 직전).

---



## 2. LayerNorm이 하는 일

LayerNorm은 시퀀스 길이가 아니라 **특징 차원(feature / hidden dim)** 축으로 통계를 잡는다. 엄밀히는 “정규화”보다 **표준화(standardization)** 에 가깝다: 평균을 빼고 표준편차로 나눈 뒤, 학습 가능한 \gamma,\beta로 스케일·시프트를 복원한다.

```python
import torch

def layer_norm(x: torch.Tensor, gamma: torch.Tensor, beta: torch.Tensor, eps: float = 1e-5):
    # x: [batch, seq, hidden]
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, keepdim=True, unbiased=False)
    x_hat = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_hat + beta
```

최근 LLM은 평균을 빼지 않는 **RMSNorm**을 자주 쓴다(T5 LayerNorm과 같은 계열). 스케일만 맞추고 중심화는 생략한다.

```python
def rms_norm(x: torch.Tensor, weight: torch.Tensor, eps: float = 1e-6):
    # Hugging Face LlamaRMSNorm과 동일한 형태
    variance = x.pow(2).mean(dim=-1, keepdim=True)
    x = x * torch.rsqrt(variance + eps)
    return weight * x
```

위치(Pre vs Post)가 학습 동역학에 미치는 영향은, 정규화가 LayerNorm이든 RMSNorm이든 **residual 경로에 대해 어디에 끼워지는지**가 더 중요하다.

## 3. Post-LN과 Pre-LN의 구조 차이



### 3.1 Post-LN (원본)

잔차 합 **이후**에 정규화한다. residual shortcut이 정규화를 통과하므로, 깊이가 커질 때 순전파 분산은 층마다 “리셋”되는 편이다. 대신 역전파에서 **출력에 가까운 파라미터의 gradient 스케일**이 커지기 쉽다.

### 3.2 Pre-LN (최근 LLM)

서브레이어 입력에 먼저 정규화를 걸고, 그 결과를 F에 넣은 뒤 **정규화되지 않은** residual x와 더한다. Identity 경로가 열려 있어 순전파에서 층이 쌓일수록 히든 상태 노름이 커질 수 있지만, 그 커진 노름이 최종(및 각) 정규화의 Jacobian을 통해 gradient를 눌러 준다.

실무 구현의 전형은 Hugging Face `LlamaDecoderLayer`다. 이름에 `post_attention_layernorm`이 있어도, 실제로는 **Attention/MLP 앞**에 두는 Pre-LN이다.

```python
# 출처: transformers .../models/llama/modeling_llama.py (LlamaDecoderLayer.forward)
# residual = x
# x = RMSNorm(x)          # input_layernorm
# x = Attention(x)
# x = residual + x
# residual = x
# x = RMSNorm(x)          # post_attention_layernorm  ← 이름만 post, 위치는 Pre-FFN
# x = MLP(x)
# x = residual + x

class PreLNDecoderLayer(torch.nn.Module):
    def __init__(self, attn, mlp, norm1, norm2):
        super().__init__()
        self.attn, self.mlp = attn, mlp
        self.norm1, self.norm2 = norm1, norm2

    def forward(self, x):
        residual = x
        x = self.attn(self.norm1(x))
        x = residual + x

        residual = x
        x = self.mlp(self.norm2(x))
        x = residual + x
        return x
```

같은 Pre-LN 계열이 Gemma·Qwen 계열에도 반복된다. Gemma 문서도 decoder-only + RMSNorm을 명시한다. (세부 변종으로 Gemma3처럼 Attention/MLP 출력을 한 번 더 정규화하는 **4-norm** 블록도 있으나, “서브레이어 전에 정규화하고 residual은 크게 열어 둔다”는 Pre-LN 철학은 같다.)

대조를 위해 Post-LN 스케치를 옆에 두면 위치가 한눈에 구분된다.

```python
class PostLNDecoderLayer(torch.nn.Module):
    def forward(self, x):
        x = self.norm1(x + self.attn(x))
        x = self.norm2(x + self.mlp(x))
        return x
```

## 4. 학습 안정성: 현상

안정한 학습은 파라미터 업데이트가 **층 전반에 고르게** 퍼지는 쪽에 가깝다. 불안정한 학습은 gradient가 **특정 층(특히 출력 근처)에 몰리거나**, 어디선가 사실상 멈추는 모습으로 나타난다. 한쪽에 몰린 큰 gradient는 큰 learning rate와 만나면 발산하기 쉽다.

Xiong et al. (2020)의 관측·이론을 요약하면:

1. **Post-LN**을 그대로 두면, 층이 깊어질수록(실험에서는 6층 → 더 깊은 설정) gradient 크기 기댓값이 **출력 쪽으로 커지는** 경향이 보인다.
2. 그래서 Post-LN은 학습 초반 learning rate를 아주 작게 시작해 천천히 올리는 **warm-up**이 사실상 필요했다. 원본 Transformer 스케줄도 warm-up을 전제로 짜여 있다.
3. **Pre-LN**에서는 초기화 시 gradient가 폭발/소멸 없이 더 잘 행동하며, 동일 과제에서 warm-up을 **제거해도** 학습이 가능했고 loss가 더 빨리 떨어지는 경우가 많았다(IWSLT14, WMT14, BERT pretraining 등).

얕은 모델(예: 6층급)에서는 Post-LN이 최종 성능에서 이득을 보이는 보고도 있다(Takase et al., 2022 등). 다만 **수십 층 이상 LLM 사전학습**에서는 발산 한 번의 비용이 워낙 커서, 업계 기본값은 Pre-LN 쪽으로 굳었다.

## 5. 수식 스케치: 왜 Pre-LN의 gradient가 작아지나

핵심 단서는 **FFN 마지막 weight**의 gradient다. chain rule로 weight gradient는


\frac{\partial \mathcal{L}}{\partial W}
= \underbrace{\frac{\partial \mathcal{L}}{\partial y}}*{\text{직후 노드 gradient}}
\cdot
\underbrace{x*{\mathrm{in}}^{\top}}_{\text{해당 weight 입력}}


형태로 분해된다. Post-LN이든 Pre-LN이든, 그 “직후”에 **LayerNorm의 Jacobian**이 끼는 지점이 있다.

LayerNorm(및 RMSNorm) Jacobian의 크기는 대략


J_{\mathrm{LN}}(x)*{2} = O\left(\frac{\sqrt{d}}{x*{2}}\right)


처럼 **입력 노름이 분모**에 들어간다(Xiong et al., Lemma 3 계열).

- **Post-LN**: 정규화 직전 히든 상태 스케일이 깊이와 거의 무관하게 \sim\sqrt{d}로 유지 → 마지막 FFN weight gradient는 O(d\sqrt{\ln d})처럼 **L에 독립**하고 크게 남기 쉽다(Theorem 1).
- **Pre-LN**: residual이 쌓이며 히든 노름이 대략 L에 비례해 커짐(Lemma 2: \mathbb{E}x^2 \propto (1+\Theta(l))d) → 최종/경로상 정규화가 gradient를 \sim 1/\sqrt{L}로 눌러 줌. 논문이 한 줄로 말하는 직관은 **“업데이트 크기가 깊이 제곱근에 반비례해 안정화된다”** 쪽이다.

따라서 Pre-LN은 “gradient를 없애는” 게 아니라, **깊은 스택에서도 층마다 비슷한 크기의 업데이트**가 들어가도록 스케일을 맞추는 장치에 가깝다. Post-LN은 그 스케일 제어를 warm-up(초반 작은 LR)에 더 많이 맡긴다.

```python
# 직관용 스케일 스케치 (실제 학습 루프가 아님)
import math

def last_ffn_grad_scale(kind: str, depth: int, d: int = 512) -> float:
    if kind == "post":
        return d * math.sqrt(math.log(d))          # L과 무관하게 큼
    if kind == "pre":
        return d * math.sqrt(math.log(d) / depth)  # ~ 1/sqrt(L)
    raise ValueError(kind)

for L in (6, 12, 24, 48):
    print(L, last_ffn_grad_scale("post", L), last_ffn_grad_scale("pre", L))
```

## 6. 실무에서의 함의

1. **깊은 LLM / DiT**를 처음부터 학습할 때 Pre-LN(또는 Pre-RMSNorm)이 기본 선택이다.
2. Post-LN을 고집하면 **긴 warm-up·보수적 LR**이 필요해지고, 하이퍼파라미터 민감도가 커진다.
3. Pre-LN만으로 만능은 아니다. 깊은 층에서 residual 기여가 약해져 **후반 층 활용이 줄어든다**는 후속 논의(예: Mix-LN, LayerNorm scaling)도 있다. 그래도 대규모 사전학습의 1순위 리스크인 **발산**을 줄이는 쪽에서는 Pre-LN이 여전히 표준이다.
4. 코드·체크포인트를 읽을 때 레이어 이름(`post_attention_layernorm`)만 보고 Post-LN으로 오해하지 말 것. Llama/Gemma류는 **Pre-블록 norm**이다.

---



## 7. 한 줄로 정리

요즘 LLM이 Pre-LN을 섞는 이유는, 정규화를 residual **안쪽(서브레이어 앞)** 에 두어 LayerNorm/RMSNorm Jacobian이 깊이 L에 따라 gradient를 \sim 1/\sqrt{L}로 눌러 주고, 그 결과 **출력 근처 업데이트 폭주와 warm-up 의존**을 줄이기 때문이다. 원본 Post-LN은 얕은 모델에서 성능 이점이 있을 수 있으나, 현대적 깊이와 학습 비용 앞에서는 안정성이 Pre-LN을 선택하게 만든다.
