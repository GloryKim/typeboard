# typeboard

Bun 설명서와 Rust, 시스템 설계, 네트워크·보안, AI 공부 노트를 모은 곳입니다. 왼쪽에서 섹션과 카테고리를 펼치거나, 위 검색창(`/`)으로 찾으세요.

## 문서 추가하는 법

- **새 글:** 알맞은 카테고리 폴더에 `.md` 파일을 넣으면 저장하는 즉시 목록과 검색에 나타납니다.
- **파일 이름:** `YYMMDD_HHMM_제목.md`(예: `261102_1530_tokio_select.md`)로 쓰면 날짜가 붙고 시간순으로 정렬됩니다. 띄어쓰기 대신 `_`를 쓰세요.
- **제목:** 파일 첫 줄의 `# 제목`이 목록과 페이지 제목이 됩니다.
- **새 카테고리:** 섹션 폴더 안에 `03_이름` 같은 폴더를 만들고, `_index.md`에 `# 이름`과 한 줄 소개를 쓰면 카드에 나옵니다. 앞의 번호는 순서만 정하고 화면과 주소에는 나오지 않습니다.
- **새 섹션:** `docs/` 바로 아래에 `08_이름` 폴더를 만듭니다. 카테고리 없이 글만 넣어도 됩니다(예: 기술 동향).
- **그림:** 문서 옆 `images/` 폴더에 넣고 `![설명](images/그림.png)`로 씁니다.
- **다른 글 링크:** `[글](../02_크레이트/260730_2356_hyper.md)`처럼 실제 파일 경로로 쓰면 됩니다. 글을 다른 카테고리로 옮겨도 파일 이름이 같으면 옛 주소는 새 위치로 이어집니다.
- **HTML:** 문서 속 HTML은 글자로 보입니다. 표 안 줄바꿈용 `<br>`만 허용됩니다.
