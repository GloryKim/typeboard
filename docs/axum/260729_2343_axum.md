## 1. Axum이란

### 개념

Axum은 **Hyper + Tower + Tokio** 위에 올라간 웹 프레임워크입니다.

| 계층 | 역할 |
|---|---|
| Tokio | 비동기 런타임 |
| Hyper | HTTP 프로토콜 구현 |
| Tower | 미들웨어(Service/Layer) 생태계 |
| Axum | 라우팅, Extractor, 응답 변환의 편한 API |

Express/FastAPI처럼 “라우트에 핸들러를 붙인다”는 모델이지만, Rust답게 **타입이 Extractor로 요청을 분해**합니다.

```text
요청 ──▶ Extractor(들) ──▶ handler ──▶ IntoResponse ──▶ 응답
              │
              └─ Path, Query, Json, State, HeaderMap, ...
```

### 체크포인트

- [ ] Axum / Hyper / Tower / Tokio 역할을 한 줄씩 말할 수 있는가
- [ ] “Extractor가 요청을 핸들러 인자로 풀어 준다”는 문장을 이해했는지

## 3. Hello World

### 코드

```rust
use axum::{routing::get, Router};

#[tokio::main]
async fn main() {
    let app = Router::new().route("/", get(|| async { "Hello, Axum!" }));

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();

    println!("listening on http://127.0.0.1:3000");
    axum::serve(listener, app).await.unwrap();
}
```

### 설명

1. `Router::new().route(path, method_router)` 로 라우트 등록
2. `get(|| async { ... })` — 핸들러는 `async fn` 또는 async 클로저
3. `TcpListener::bind` → `axum::serve` (0.7부터 이 패턴; 옛 `Server::bind`는 폐기)

검증:

```bash
curl http://127.0.0.1:3000/
# Hello, Axum!
```

### 핸들러를 함수로 분리

```rust
use axum::{routing::get, Router};

async fn hello() -> &'static str {
    "Hello, Axum!"
}

#[tokio::main]
async fn main() {
    let app = Router::new().route("/", get(hello));

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

- [ ] 서버 띄우고 curl로 응답 확인

## 4. 라우팅 기초

### HTTP 메서드

```rust
use axum::{
    routing::{delete, get, patch, post, put},
    Router,
};

async fn list() -> &'static str { "GET list" }
async fn create() -> &'static str { "POST create" }
async fn replace() -> &'static str { "PUT replace" }
async fn update() -> &'static str { "PATCH update" }
async fn remove() -> &'static str { "DELETE remove" }

fn app() -> Router {
    Router::new()
        .route("/items", get(list).post(create))
        .route("/items/{id}", put(replace).patch(update).delete(remove))
}
```

같은 path에 메서드를 **체이닝**할 수 있습니다: `get(a).post(b)`.

### `any` — 모든 메서드

```rust
use axum::{routing::any, Router};

async fn catch_all() -> &'static str {
    "any method"
}

fn app() -> Router {
    Router::new().route("/ping", any(catch_all))
}
```

### fallback — 404

```rust
use axum::{
    http::StatusCode,
    response::IntoResponse,
    routing::get,
    Router,
};

async fn home() -> &'static str {
    "home"
}

async fn not_found() -> impl IntoResponse {
    (StatusCode::NOT_FOUND, "페이지를 찾을 수 없습니다")
}

fn app() -> Router {
    Router::new()
        .route("/", get(home))
        .fallback(not_found)
}
```

### 메서드 불일치 (405)

등록된 path에 잘못된 메서드로 오면 Axum이 기본적으로 **405 Method Not Allowed**를 돌려줍니다. fallback은 “매칭되는 라우트가 없을 때”입니다.

### 체크포인트

- [ ] `/items`에 GET/POST, `/items/{id}`에 PUT/PATCH/DELETE 달아 보기
- [ ] 없는 경로에 fallback이 동작하는지 확인

## 5. 경로 파라미터

### 0.8 문법: `{id}`

```rust
use axum::{extract::Path, routing::get, Router};
use serde::Deserialize;

async fn user(Path(user_id): Path<u64>) -> String {
    format!("user id = {user_id}")
}

#[derive(Deserialize)]
struct PostParams {
    user_id: u64,
    post_id: u64,
}

async fn post(Path(p): Path<PostParams>) -> String {
    format!("user {} post {}", p.user_id, p.post_id)
}

fn app() -> Router {
    Router::new()
        .route("/users/{user_id}", get(user))
        .route("/users/{user_id}/posts/{post_id}", get(post))
}
```

### 와일드카드: `{*path}`

```rust
use axum::{extract::Path, routing::get, Router};

async fn assets(Path(path): Path<String>) -> String {
    format!("requested asset path: {path}")
}

fn app() -> Router {
    // /assets/a/b/c.png → path = "a/b/c.png"
    Router::new().route("/assets/{*path}", get(assets))
}
```

### 0.7 과의 차이 (중요)

| 버전 | path 파라미터 |
|---|---|
| 0.7 | `/users/:id`, 와일드카드 `/*path` |
| 0.8 | `/users/{id}`, 와일드카드 `/{*path}` |

이 저장소 코드가 0.7이라면 `:id`를 써야 합니다. 새 학습 코드는 `{id}`를 쓰세요.

### 파싱 실패

`Path<u64>`인데 `"abc"`가 오면 **400 Bad Request**가 됩니다. 커스텀 에러로 바꾸려면 [13절](#13-에러-핸들링)의 `FromRequestParts` / rejection 커스터마이즈를 봅니다.

### 체크포인트

- [ ] 단일/다중 path 파라미터 핸들러 작성
- [ ] 숫자 자리에 문자열을 넣어 400 확인

## 6. 쿼리 파라미터

```rust
use axum::{extract::Query, routing::get, Json, Router};
use serde::{Deserialize, Serialize};

#[derive(Debug, Deserialize, Serialize)]
struct Search {
    q: String,
    #[serde(default = "default_page")]
    page: u32,
    #[serde(default = "default_limit")]
    limit: u32,
}

fn default_page() -> u32 { 1 }
fn default_limit() -> u32 { 20 }

async fn search(Query(params): Query<Search>) -> Json<Search> {
    Json(params)
}

fn app() -> Router {
    Router::new().route("/search", get(search))
}
```

```bash
curl 'http://127.0.0.1:3000/search?q=axum&page=2'
# {"q":"axum","page":2,"limit":20}
```

## 7. 헤더 / 쿠키

### HeaderMap

```rust
use axum::{
    http::{HeaderMap, header::USER_AGENT},
    routing::get,
    Router,
};

async fn whoami(headers: HeaderMap) -> String {
    headers
        .get(USER_AGENT)
        .and_then(|v| v.to_str().ok())
        .unwrap_or("unknown")
        .to_string()
}

fn app() -> Router {
    Router::new().route("/whoami", get(whoami))
}
```

### TypedHeader (axum-extra)

```rust
use axum::{routing::get, Router};
use axum_extra::TypedHeader;
use headers::Authorization;
use headers::authorization::Bearer;

async fn secret(
    TypedHeader(Authorization(bearer)): TypedHeader<Authorization<Bearer>>,
) -> String {
    format!("token = {}", bearer.token())
}

fn app() -> Router {
    Router::new().route("/secret", get(secret))
}
```

`Cargo.toml`에 `headers` 크레이트와 `axum-extra`의 `typed-header` feature가 필요합니다.

### 쿠키 (axum-extra)

```rust
use axum::{routing::get, Router};
use axum_extra::extract::cookie::{Cookie, CookieJar};

async fn read_cookie(jar: CookieJar) -> String {
    jar.get("session")
        .map(|c| format!("session={}", c.value()))
        .unwrap_or_else(|| "no session".into())
}

async fn set_cookie(jar: CookieJar) -> CookieJar {
    jar.add(Cookie::new("session", "abc123"))
}

fn app() -> Router {
    Router::new()
        .route("/cookie", get(read_cookie))
        .route("/cookie/set", get(set_cookie))
}
```

### 체크포인트

- [ ] User-Agent를 읽어 반환

## 8. JSON 요청·응답

### 기본

```rust
use axum::{routing::post, Json, Router};
use serde::{Deserialize, Serialize};

#[derive(Deserialize)]
struct CreateUser {
    name: String,
    email: String,
}

#[derive(Serialize)]
struct User {
    id: u64,
    name: String,
    email: String,
}

async fn create_user(Json(body): Json<CreateUser>) -> Json<User> {
    Json(User {
        id: 1,
        name: body.name,
        email: body.email,
    })
}

fn app() -> Router {
    Router::new().route("/users", post(create_user))
}
```

```bash
curl -X POST http://127.0.0.1:3000/users \
  -H 'content-type: application/json' \
  -d '{"name":"kim","email":"kim@example.com"}'
```

### 상태 코드와 함께

```rust
use axum::{
    http::StatusCode,
    response::IntoResponse,
    routing::post,
    Json, Router,
};
use serde::{Deserialize, Serialize};

#[derive(Deserialize)]
struct CreateUser {
    name: String,
}

#[derive(Serialize)]
struct User {
    id: u64,
    name: String,
}

async fn create_user(Json(body): Json<CreateUser>) -> impl IntoResponse {
    let user = User {
        id: 42,
        name: body.name,
    };
    (StatusCode::CREATED, Json(user))
}
```

### JSON이 아닐 때

`Content-Type`이 JSON이 아니거나 body가 깨지면 `Json` extractor가 rejection → 기본 400입니다.

### 큰 JSON / 제한

```rust
use axum::extract::DefaultBodyLimit;
use axum::{routing::post, Json, Router};
use serde::Deserialize;

#[derive(Deserialize)]
struct Payload {
    data: String,
}

async fn ingest(Json(_p): Json<Payload>) -> &'static str {
    "ok"
}

fn app() -> Router {
    Router::new()
        .route("/ingest", post(ingest))
        // 기본은 2MB. 필요하면 키우거나 줄인다.
        .layer(DefaultBodyLimit::max(1024 * 1024)) // 1MB
}
```

- [ ] POST + Json + 201 Created 응답

### multipart 파일 업로드

`axum` feature `multipart` 필요.

```rust
use axum::{
    extract::Multipart,
    http::StatusCode,
    response::IntoResponse,
    routing::post,
    Router,
};

async fn upload(mut multipart: Multipart) -> impl IntoResponse {
    while let Some(field) = multipart.next_field().await.unwrap() {
        let name = field.name().unwrap_or("unknown").to_string();
        let file_name = field.file_name().map(|s| s.to_string());
        let data = field.bytes().await.unwrap();

        println!(
            "field={name} file={:?} bytes={}",
            file_name,
            data.len()
        );
    }
    (StatusCode::OK, "uploaded")
}

fn app() -> Router {
    Router::new().route("/upload", post(upload))
}
```

```bash
curl -X POST http://127.0.0.1:3000/upload \
  -F 'file=@./README.md'
```

## 11. 상태(State) 공유

### 개념

핸들러끼리 DB 풀, 설정, 인메모리 저장소를 공유하려면 `State<T>`를 씁니다.
`T`는 `Clone + Send + Sync + 'static`이어야 하므로 보통 `Arc`로 감쌉니다.

### Arc + Mutex 인메모리

```rust
use axum::{
    extract::State,
    http::StatusCode,
    response::IntoResponse,
    routing::{get, post},
    Json, Router,
};
use serde::{Deserialize, Serialize};
use std::sync::{Arc, Mutex};

#[derive(Clone)]
struct AppState {
    items: Arc<Mutex<Vec<Item>>>,
}

#[derive(Clone, Serialize)]
struct Item {
    id: u64,
    title: String,
}

#[derive(Deserialize)]
struct NewItem {
    title: String,
}

async fn list(State(state): State<AppState>) -> Json<Vec<Item>> {
    let items = state.items.lock().unwrap().clone();
    Json(items)
}

async fn create(
    State(state): State<AppState>,
    Json(body): Json<NewItem>,
) -> impl IntoResponse {
    let mut guard = state.items.lock().unwrap();
    let id = guard.len() as u64 + 1;
    let item = Item {
        id,
        title: body.title,
    };
    guard.push(item.clone());
    (StatusCode::CREATED, Json(item))
}

#[tokio::main]
async fn main() {
    let state = AppState {
        items: Arc::new(Mutex::new(vec![])),
    };

    let app = Router::new()
        .route("/items", get(list).post(create))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

### 비동기 락이 필요할 때

동기 `std::sync::Mutex`는 락을 잡은 채 `.await`하면 안 됩니다.
핸들러 안에서 lock → 짧은 작업 → unlock 패턴이면 OK.
오래 기다리거나 await가 끼면 `tokio::sync::Mutex`를 쓰세요.

```rust
use tokio::sync::Mutex;

#[derive(Clone)]
struct AppState {
    items: Arc<Mutex<Vec<String>>>,
}

async fn push(State(state): State<AppState>, Json(v): Json<String>) {
    state.items.lock().await.push(v);
}
```

### 설정 구조체

```rust
#[derive(Clone)]
struct Config {
    database_url: String,
    jwt_secret: String,
}

#[derive(Clone)]
struct AppState {
    config: Config,
    // db: sqlx::PgPool, ...
}
```

### Extension vs State

| | State | Extension |
|---|---|---|
| 주입 | `.with_state(s)` | `.layer(Extension(v))` |
| 추출 | `State<T>` | `Extension<T>` |
| 권장 | 앱 전역 의존성 | 미들웨어가 요청마다 꽂는 값 |

요즘은 **State를 기본**, Extension은 “요청 스코프 부가 정보”에 쓰는 편이 낫습니다.

- [ ] 인메모리 CRUD list/create
- [ ] `with_state` 없이 `State`만 쓰면 컴파일 에러나는지 확인

## 12. Extractor 심화

### 인자 순서

Extractor는 크게 두 종류입니다.

| 종류 | 트레이트 | 예 | body |
|---|---|---|---|
| Parts | `FromRequestParts` | `Path`, `Query`, `State`, `HeaderMap` | 안 읽음 |
| Body | `FromRequest` | `Json`, `Form`, `Multipart`, `Bytes`, `String` | 읽음 |

Parts가 먼저 돌고, 그다음 Body extractor가 돕니다. **Body를 소비하는 Extractor는 핸들러당 하나만** 둡니다. 인자는 Parts를 앞에, Body를 마지막에 두는 게 관례입니다.

```rust
// OK — Path/Query/State 는 body 와 무관
async fn ok(
    State(state): State<AppState>,
    Path(id): Path<u64>,
    Query(q): Query<Search>,
    Json(body): Json<Payload>,
) { ... }

// 불가 — Json 과 Bytes 둘 다 body 를 읽으려 함
// async fn bad(Json(j): Json<Payload>, body: Bytes) { ... }
```

### 커스텀 Extractor

```rust
use axum::{
    extract::FromRequestParts,
    http::request::Parts,
    http::StatusCode,
};

struct RequestId(String);

impl<S> FromRequestParts<S> for RequestId
where
    S: Send + Sync,
{
    type Rejection = (StatusCode, &'static str);

    async fn from_request_parts(parts: &mut Parts, _state: &S) -> Result<Self, Self::Rejection> {
        let id = parts
            .headers
            .get("x-request-id")
            .and_then(|v| v.to_str().ok())
            .map(|s| s.to_string())
            .unwrap_or_else(|| uuid::Uuid::new_v4().to_string());

        Ok(RequestId(id))
    }
}

async fn handler(RequestId(id): RequestId) -> String {
    format!("request-id={id}")
}
```

## 13. 에러 핸들링

### Result + IntoResponse

```rust
use axum::{
    extract::Path,
    http::StatusCode,
    response::{IntoResponse, Response},
    routing::get,
    Json, Router,
};
use serde_json::json;

enum ApiError {
    NotFound,
    BadRequest(String),
    Internal(String),
}

impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let (status, msg) = match self {
            ApiError::NotFound => (StatusCode::NOT_FOUND, "not found".to_string()),
            ApiError::BadRequest(m) => (StatusCode::BAD_REQUEST, m),
            ApiError::Internal(m) => (StatusCode::INTERNAL_SERVER_ERROR, m),
        };
        (status, Json(json!({ "error": msg }))).into_response()
    }
}

async fn find_user(Path(id): Path<u64>) -> Result<Json<serde_json::Value>, ApiError> {
    if id == 0 {
        return Err(ApiError::BadRequest("id must be > 0".into()));
    }
    if id == 404 {
        return Err(ApiError::NotFound);
    }
    Ok(Json(json!({ "id": id, "name": "kim" })))
}

fn app() -> Router {
    Router::new().route("/users/{id}", get(find_user))
}
```

### Timeout

두 가지가 자주 섞여 헷갈립니다.

**A. `tower_http::timeout::TimeoutLayer`** — 타임아웃 시 **응답(기본 408)** 을 직접 만듦. `HandleErrorLayer` 불필요.

```rust
use axum::{routing::get, Router};
use std::time::Duration;
use tower_http::timeout::TimeoutLayer;

    Router::new()
        .route("/", get(|| async { "ok" }))
        .layer(TimeoutLayer::with_status_code(
            axum::http::StatusCode::REQUEST_TIMEOUT,
            Duration::from_secs(10),
        ))
}
```

**B. `tower` 타임아웃 (`ServiceBuilder::timeout`)** — 에러를 내기 때문에 `HandleErrorLayer`로 응답으로 바꿔야 함.

```rust
use axum::{
    error_handling::HandleErrorLayer,
    http::StatusCode,
    routing::get,
    BoxError, Router,
};
use std::time::Duration;
use tower::ServiceBuilder;

fn app() -> Router {
    Router::new()
        .route("/", get(|| async { "ok" }))
        .layer(
            ServiceBuilder::new()
                .layer(HandleErrorLayer::new(|err: BoxError| async move {
                    if err.is::<tower::timeout::error::Elapsed>() {
                        (StatusCode::REQUEST_TIMEOUT, "timeout".to_string())
                    } else {
                        (StatusCode::INTERNAL_SERVER_ERROR, format!("internal: {err}"))
                    }
                }))
                .timeout(Duration::from_secs(10)),
        )
}
```

(`tower-http`의 `timeout` feature는 A안용.)

## 18. 인증 패턴

완전한 JWT 라이브러리 선택은 프로젝트마다 다르지만, **패턴**은 공통입니다.

### Bearer 토큰 Extractor

```rust
use axum::{
    extract::FromRequestParts,
    http::request::Parts,
    http::StatusCode,
};

struct AuthUser {
    user_id: u64,
}

impl<S> FromRequestParts<S> for AuthUser
where
    S: Send + Sync,
{
    type Rejection = (StatusCode, &'static str);

    async fn from_request_parts(parts: &mut Parts, _state: &S) -> Result<Self, Self::Rejection> {
        let auth = parts
            .headers
            .get(axum::http::header::AUTHORIZATION)
            .and_then(|v| v.to_str().ok())
            .ok_or((StatusCode::UNAUTHORIZED, "missing authorization"))?;

        let token = auth
            .strip_prefix("Bearer ")
            .ok_or((StatusCode::UNAUTHORIZED, "invalid authorization"))?;

        // 실제로는 JWT verify
        if token != "valid-token" {
            return Err((StatusCode::UNAUTHORIZED, "invalid token"));
        }

        Ok(AuthUser { user_id: 1 })
    }
}

async fn me(user: AuthUser) -> String {
    format!("user_id={}", user.user_id)
}
```

### 로그인 → 토큰 발급 (스케치)

## 19. WebSocket

`axum` feature `ws` 필요.

```rust
use axum::{
    extract::ws::{Message, WebSocket, WebSocketUpgrade},
    response::IntoResponse,
    routing::get,
    Router,
};

async fn ws_handler(ws: WebSocketUpgrade) -> impl IntoResponse {
    ws.on_upgrade(handle_socket)
}

async fn handle_socket(mut socket: WebSocket) {
    // WebSocket::recv / send 를 쓰면 SinkExt/StreamExt 없이도 동작한다.
    while let Some(Ok(msg)) = socket.recv().await {
        match msg {
            Message::Text(text) => {
                let reply = format!("echo: {text}");
                if socket.send(Message::Text(reply.into())).await.is_err() {
                    break;
                }
            }
            Message::Close(_) => break,
            _ => {}
        }
    }
}

fn app() -> Router {
    Router::new().route("/ws", get(ws_handler))
}
```

브라우저:

```javascript
const ws = new WebSocket("ws://127.0.0.1:3000/ws");
ws.onmessage = (e) => console.log(e.data);
ws.onopen = () => ws.send("hello");
```

## 21. Graceful Shutdown

```rust
use axum::{routing::get, Router};

async fn hello() -> &'static str {
    "hello"
}

#[tokio::main]
async fn main() {
    let app = Router::new().route("/", get(hello));

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();

    axum::serve(listener, app)
        .with_graceful_shutdown(shutdown_signal())
        .await
        .unwrap();
}

async fn shutdown_signal() {
    let ctrl_c = async {
        tokio::signal::ctrl_c()
            .await
            .expect("failed to install Ctrl+C handler");
    };

    #[cfg(unix)]
    let terminate = async {
        tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate())
            .expect("failed to install signal handler")
            .recv()
            .await;
    };

    #[cfg(not(unix))]
    let terminate = std::future::pending::<()>();

    tokio::select! {
        _ = ctrl_c => {},
        _ = terminate => {},
    }

    println!("signal received, shutting down");
}
```

Ctrl+C 시 진행 중 요청을 마무리한 뒤 종료합니다.

```rust
                .header("content-type", "application/json")

                .unwrap(),
        )
        .await
        .unwrap();

    assert_eq!(response.status(), StatusCode::CREATED);
}
```

## 23. SQLx CRUD

PostgreSQL 예시 스케치입니다. 실제 DB가 없으면 컴파일만 맞추고 실행은 건너뛰세요.

```toml
sqlx = { version = "0.8", features = ["runtime-tokio", "postgres", "chrono", "uuid"] }
```

```rust
use axum::{
    extract::{Path, State},
    http::StatusCode,
    response::IntoResponse,
    routing::{get, post},
    Json, Router,
};
use serde::{Deserialize, Serialize};
use sqlx::PgPool;

#[derive(Clone)]
struct AppState {
    pool: PgPool,
}

#[derive(Serialize, sqlx::FromRow)]
struct Todo {
    id: i64,
    title: String,
    done: bool,
}

#[derive(Deserialize)]
struct NewTodo {
    title: String,
}

async fn list(State(state): State<AppState>) -> Result<Json<Vec<Todo>>, StatusCode> {
    let rows = sqlx::query_as::<_, Todo>("SELECT id, title, done FROM todos ORDER BY id")
        .fetch_all(&state.pool)
        .await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    Ok(Json(rows))
}

async fn create(
    State(state): State<AppState>,
    Json(body): Json<NewTodo>,
) -> Result<impl IntoResponse, StatusCode> {
    let row = sqlx::query_as::<_, Todo>(
        "INSERT INTO todos (title, done) VALUES ($1, false) RETURNING id, title, done",
    )
    .bind(&body.title)
    .fetch_one(&state.pool)
    .await
    .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;

    Ok((StatusCode::CREATED, Json(row)))
}

async fn get_one(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> Result<Json<Todo>, StatusCode> {
    let row = sqlx::query_as::<_, Todo>("SELECT id, title, done FROM todos WHERE id = $1")
        .bind(id)
        .fetch_optional(&state.pool)
        .await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?
        .ok_or(StatusCode::NOT_FOUND)?;
    Ok(Json(row))
}

#[tokio::main]
async fn main() {
    let database_url = std::env::var("DATABASE_URL").expect("DATABASE_URL");
    let pool = PgPool::connect(&database_url).await.unwrap();

    let state = AppState { pool };

    let app = Router::new()
        .route("/todos", get(list).post(create))
        .route("/todos/{id}", get(get_one))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

마이그레이션 SQL 예:

```sql
CREATE TABLE todos (
  id BIGSERIAL PRIMARY KEY,
  title TEXT NOT NULL,
  done BOOLEAN NOT NULL DEFAULT false
);
```

## 24. 실전: 작은 REST API 한 방에

인메모리 할 일 API + 로깅 + CORS + 에러 타입 + graceful shutdown 종합 예제입니다.

```rust
use axum::{
    extract::{Path, State},
    http::StatusCode,
    response::{IntoResponse, Response},
    routing::{get, post},
    Json, Router,
};
use serde::{Deserialize, Serialize};
use serde_json::json;
use std::sync::{Arc, Mutex};
use tower_http::{cors::CorsLayer, trace::TraceLayer};
use tracing_subscriber::EnvFilter;
use uuid::Uuid;

#[derive(Clone)]
struct AppState {
    todos: Arc<Mutex<Vec<Todo>>>,
}

#[derive(Clone, Serialize)]
struct Todo {
    id: Uuid,
    title: String,
    done: bool,
}

#[derive(Deserialize)]
struct CreateTodo {
    title: String,
}

#[derive(Deserialize)]
struct UpdateTodo {
    title: Option<String>,
    done: Option<bool>,
}

enum ApiError {
    NotFound,
    BadRequest(&'static str),
}

impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let (status, msg) = match self {
            ApiError::NotFound => (StatusCode::NOT_FOUND, "not found"),
            ApiError::BadRequest(m) => (StatusCode::BAD_REQUEST, m),
        };
        (status, Json(json!({ "error": msg }))).into_response()
    }
}

async fn health() -> Json<serde_json::Value> {
    Json(json!({ "status": "ok" }))
}

async fn list(State(state): State<AppState>) -> Json<Vec<Todo>> {
    Json(state.todos.lock().unwrap().clone())
}

async fn create(
    State(state): State<AppState>,
    Json(body): Json<CreateTodo>,
) -> Result<(StatusCode, Json<Todo>), ApiError> {
    if body.title.trim().is_empty() {
        return Err(ApiError::BadRequest("title required"));
    }
    let todo = Todo {
        id: Uuid::new_v4(),
        title: body.title,
        done: false,
    };
    state.todos.lock().unwrap().push(todo.clone());
    Ok((StatusCode::CREATED, Json(todo)))
}

async fn get_one(
    State(state): State<AppState>,
    Path(id): Path<Uuid>,
) -> Result<Json<Todo>, ApiError> {
    state
        .todos
        .lock()
        .unwrap()
        .iter()
        .find(|t| t.id == id)
        .cloned()
        .map(Json)
        .ok_or(ApiError::NotFound)
}

async fn update(
    State(state): State<AppState>,
    Path(id): Path<Uuid>,
    Json(body): Json<UpdateTodo>,
) -> Result<Json<Todo>, ApiError> {
    let mut guard = state.todos.lock().unwrap();
    let todo = guard.iter_mut().find(|t| t.id == id).ok_or(ApiError::NotFound)?;
    if let Some(title) = body.title {
        if title.trim().is_empty() {
            return Err(ApiError::BadRequest("title empty"));
        }
        todo.title = title;
    }
    if let Some(done) = body.done {
        todo.done = done;
    }
    Ok(Json(todo.clone()))
}

async fn remove(
    State(state): State<AppState>,
    Path(id): Path<Uuid>,
) -> Result<StatusCode, ApiError> {
    let mut guard = state.todos.lock().unwrap();
    let before = guard.len();
    guard.retain(|t| t.id != id);
    if guard.len() == before {
        return Err(ApiError::NotFound);
    }
    Ok(StatusCode::NO_CONTENT)
}

fn app(state: AppState) -> Router {
    Router::new()
        .route("/health", get(health))
        .route("/todos", get(list).post(create))
        .route(
            "/todos/{id}",
            get(get_one)
                .patch(update)
                .delete(remove),
        )
        .layer(CorsLayer::permissive())
        .layer(TraceLayer::new_for_http())
        .with_state(state)
}

#[tokio::main]
async fn main() {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .init();

    let state = AppState {
        todos: Arc::new(Mutex::new(Vec::new())),
    };

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();

    tracing::info!("listening on http://127.0.0.1:3000");

    axum::serve(listener, app(state))
        .with_graceful_shutdown(async {
            tokio::signal::ctrl_c().await.ok();
        })
        .await
        .unwrap();
}
```

수동 테스트:

```bash
curl http://127.0.0.1:3000/health

curl -X POST http://127.0.0.1:3000/todos \
  -H 'content-type: application/json' \
  -d '{"title":"learn axum"}'

curl http://127.0.0.1:3000/todos

# id는 위 응답의 uuid
curl -X PATCH http://127.0.0.1:3000/todos/<id> \
  -H 'content-type: application/json' \
  -d '{"done":true}'

curl -X DELETE http://127.0.0.1:3000/todos/<id>
```

## 25. 0.7 vs 0.8 치트시트

이 저장소 `api`/`backend`는 **axum 0.7**입니다.

| 항목 | 0.7 | 0.8 |
|---|---|---|
| path param | `/users/:id` | `/users/{id}` |
| wildcard | `/*path` | `/{*path}` |
| serve | `axum::serve(listener, app)` | 동일 |
| MethodRouter 체이닝 | `get().post()` | 동일 |
| State | `with_state` / `State` | 동일 |

0.7 Hello (저장소와 동일 계열):

```rust
use axum::{routing::get, Router};

#[tokio::main]
async fn main() {
    let app = Router::new().route("/", get(|| async { "ok" }));
    let listener = tokio::net::TcpListener::bind("127.0.0.1:3002")
        .await
        .unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

0.7 path:

```rust
.route("/users/:id", get(user))
```

0.8 path:

```rust
.route("/users/{id}", get(user))
```

업그레이드 시 검색 치환:

1. `:param` → `{param}`
2. `/*rest` → `/{*rest}`
3. `tower-http` 메이저 버전도 같이 맞춤 (0.5 → 0.6 등)

## 26. 자주 하는 실수

1. **옛 `Server::bind` 튜토리얼 복사**  
   → `TcpListener` + `axum::serve` 사용.

2. **0.7 코드에 `{id}` / 0.8 코드에 `:id`**  
   → 버전과 path 문법을 맞출 것.

3. **`State`만 쓰고 `with_state` 안 함**  
   → 컴파일 에러. Router 끝에 `.with_state(state)`.

4. **`Mutex` 잠근 채 `.await`**  
   → `std::sync::Mutex`면 금지. 짧게 쓰거나 `tokio::sync::Mutex`.

5. **body Extractor를 두 개** (`Json` + `Bytes` 등)  
   → body는 한 번만 읽힘. 하나만.

6. **Layer 순서 착각**  
   → 나중에 `.layer`한 쪽이 요청을 먼저 봄.

7. **CORS를 API에만 안 붙임**  
   → 브라우저 클라이언트가 있으면 `CorsLayer` 필요. curl만 쓸 때는 무관.

8. **에러를 `unwrap`으로만 처리**  
   → `ApiError: IntoResponse` + `Result`로 클라이언트에 의미 있는 상태 코드.

9. **테스트에서 `ServiceExt` import 누락**  
   → `use tower::ServiceExt;` 해야 `.oneshot` 사용 가능.

10. **정적 feature 누락**  
    - multipart → `features = ["multipart"]`
    - websocket → `features = ["ws"]`
    - cookie → `axum-extra` feature

## 부록 E. 이 문서에서 깊게 안 다룬 개념

핵심 루트는 위에서 다루었고, 아래는 다음에 이어서 보면 좋은 항목입니다.

| 주제 | 요지 |
|---|---|
| `Option<Extractor>` / `Result<Extractor, Rejection>` | 헤더·쿼리가 없을 때 404 대신 `None`/`Err`로 받기 |
| `middleware::from_fn_with_state` | 미들웨어에서 `State` 접근 |
| `Router::route_layer` | 라우팅 **이후**에만 레이어 (매칭된 라우트에만) |
| `MatchedPath` / `OriginalUri` | 매칭된 경로 템플릿, rewrite 전 URI |
| `ConnectInfo<SocketAddr>` | 클라이언트 IP (`into_make_service_with_connect_info`) |
| `tower_http::request_id` | `x-request-id` 생성·전파 |
| `CatchPanicLayer` | 핸들러 패닉 → 500 |
| `NormalizePathLayer` | trailing slash 정규화 |
| TLS / HTTPS | `axum-server` + rustls, 또는 앞단 리버스 프록시 |
| OpenAPI | `utoipa` + `utoipa-swagger-ui` |
| 입력 검증 | `validator` / `garde` + 커스텀 Extractor |
| Rate limit | `tower` limit / 외부 미들웨어 / Redis |
| 스트리밍 응답 | `Body::from_stream`, `AsyncRead` 파일 전송 |
| `method_not_allowed_fallback` | 405 응답 커스터마이즈 |
| 추출 실패 JSON화 | `JsonRejection` 래핑 Extractor |
